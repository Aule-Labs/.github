# Aule Labs

Aule Labs is an independent AI research and engineering lab run by two students.

We're interested in understanding how artificial intelligence works, experimenting with new ideas, and building software.

## Projects

### SimAPI — Simulations you can trust
A physics validator for robot runs. It checks a recording against joint limits, changes in motion, and gaps in recording, then shows the exact samples behind each result, so you can see which moment broke a run and why.
[simapilander.vercel.app](https://simapilander.vercel.app)

### handoff-limit-skill
Writes a `handoff.md` with everything about the run (what it did, what's left, what the next agent needs to know) the moment your agent drops below 5% of its usage, and plans around the limit so long runs end cleanly instead of dead.
`npx --yes handoff-limit` · [repo](https://github.com/Aule-Labs/handoff-limit-skill) · [npm](https://www.npmjs.com/package/handoff-limit)

### keepalive-render
Keeps a free-tier Render service awake by pinging it every 10 minutes.
`npx keepalive-render` · [repo](https://github.com/Aule-Labs/keepAlive) · [npm](https://www.npmjs.com/package/keepalive-render)
